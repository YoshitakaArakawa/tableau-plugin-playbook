# Tableau プラグイン プレイブック

Claude に入れた Tableau プラグインを、もっとうまく使ってもらうための補強キットです。claude.ai の「マーケットプレイスを追加」から入れられます。

Tableau プラグインだけでも、Claude は Tableau のデータを読み、ワークブックを作って Tableau Cloud に公開できます。ただ、そのままだと色や数字の書式、項目の名前が Tableau の既定のまま仕上がりがちです。このキットは、Claude に「作る順番」と「見た目のルール」、「ワークブックの書き方のコツ」を渡して、人に見せられるダッシュボードに仕上げてもらうためのものです。

## 入っているもの

スキルが1つ入ったプラグイン（`tableau-plugin-playbook`）です。スキルの中身は次のとおりです。

- 進め方: まず Claude のダッシュボードで分析を見せ、頼まれたら Tableau のワークブックにして公開し、仕上がりを点検して直す
- 見た目のルール: 色・数字の書式・名前・主要な数字の見せ方・並べ方
- 参考資料3つ: ワークブックの土台、書式と落とし穴、見た目の判断と定石（Claude が読むための技術資料で、人が読まなくても使えます）

## 必要なもの

- Claude の有料プラン（Pro 以上）
- Tableau Cloud のアカウント（Tableau Developer Program のサイトでも試せます）
- Tableau プラグイン

## 入れ方

web・デスクトップアプリ・スマホのブラウザで同じ手順です。

1. **Tableau プラグインを入れる**: 「カスタマイズ → プラグイン」で「マーケットプレイスを追加」を開き、`YoshitakaArakawa/tableau-plugin-claude-mirror` を追加して「Tableau」をインストールします（公式の [tableau/tableau-plugin](https://github.com/tableau/tableau-plugin) のビルド済み版の写しです）
2. **このキットを入れる**: 同じく「マーケットプレイスを追加」で `YoshitakaArakawa/tableau-plugin-playbook` を追加し、「Tableau プラグイン プレイブック」をインストールします
3. **Tableau にサインインする**: 「コネクタ」で Tableau に接続し、Tableau Cloud のサインイン画面でサインインして許可します
4. **コード実行をオンにする**: 「設定 → 機能」でコード実行をオンにします
5. **新しいチャットで頼む**: 下の例のように頼みます

## 頼み方の例

最初は、同僚に頼むくらいの書き方で、Claude のダッシュボードを作ってもらいます。

```
来週から経営会議で Superstore の数字を毎週見ることになったんだけど、そのダッシュボード作ってもらえる？データは Tableau Cloud にある Sample SuperStore でいいよ。

いちばん気にしてるのは、お客さんにちゃんと使い続けてもらえてるかってところ。売上が伸びてても、一部のお客さん頼みだったらちょっと怖いじゃない。なので売上・注文数・顧客数あたりを軸にして、新しく来てくれた人とリピートしてくれてる人がどう動いてるか、どの地域やセグメントで増えてて、どこで減ってるかが見たい。

会議の頭の30秒で「今週どうだった？気になるところはどこ？」が分かればOK。データが古いから、一番新しい週を今週ってことにして、ここ数週と比べる感じで。
```

気に入ったら、同じチャットで Tableau にしてもらいます。

```
いい感じ。これ Tableau のダッシュボードにして、みんなが見られるように Tableau Cloud に上げといてもらえる？
```

公開先のプロジェクトや、Tableau Cloud のアドレスを聞かれたら答えてください。途中でツールの使用許可を求められたら「許可」を押します。

## うまくいかないとき

**仕上がりの画像が取れない、公開できない**

Claude の作業環境から、Tableau の画像置き場への通信が止められていることがあります。エラーに出てくる `〜.amazonaws.com` で終わるアドレスを控えて、「設定 → 機能」の許可リストに追加してください。会社のアカウントでは、管理者の設定が必要です。

**見た目が思いどおりでない**

チャットで「色を〜にして」「〜を日本語にして」のように伝えると、直して公開し直してくれます。
